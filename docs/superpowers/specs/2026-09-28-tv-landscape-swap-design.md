# TV 가독성·가로 배치·자리 바꾸기·고정 표시 개선 스펙

- 작성일: 2026-09-28
- 대상: https://seat-changer-two.vercel.app (989-alt/seat-changer), 브랜치 `feat/tv-landscape-swap`
- 상태: 설계 1~5절 사용자 승인 완료(2026-09-28) → writing-plans로 구현 계획 작성

## 0. 배경

v2 배포 후 현장 교사 피드백 4건.

1. TV(전자칠판 아님)로 보면 화면과 글자가 작아 학생들이 잘 안 보인다. 확대가 되는가?
2. 배치 화면과 인쇄물이 둘 다 세로 모드다. TV와 컴퓨터 화면이 가로이니 가로로 보고 싶다.
3. 이미 배치된 학생끼리 자리 바꾸기는 어떻게 쓰는가?
4. 고정 학생 자리가 동그란 점으로 표시되는데 없앨 수 있는가?

## 1. 조사 결과 (라이브 사이트 Playwright 실측, 2026-09-28)

| 항목 | 원인 |
|---|---|
| 1 | 발표 화면은 배치도를 남는 공간에 맞춰 `transform: scale`로 키우는데, 배치도가 세로형이라 높이에 막힌다. 1920x1080 전체 화면에서 배치도 폭 776px(화면의 40%), 이름 42px. 1080p 일반 브라우저 창(1920x937)에서 28px, 노트북 1366x768 창(1366x625)에서 **15px**. 제목 칠판("6-5 자리 배치")과 배치도 안 "칠판" 두 개, 큰 조작 막대(약 105px)가 세로 공간을 먹는다. 브라우저 확대(Ctrl +)는 막대만 키우고 배치도는 남는 공간에 맞춰 줄어 역효과다. |
| 2 | 시험대형·짝꿍의 `lg` 이름표 폭이 grid `auto` 열이라 이름 길이만큼만 잡힌다(약 80px x 96px, 세로로 길쭉). 배치도 전체가 세로형이 된다. 인쇄도 세로 용지에 같은 배치도가 원래 크기로 찍혀 종이 아래 절반이 빈다. |
| 3 | 교환 기능은 있다(뽑기가 끝나고 전부 공개된 뒤 자리 두 곳을 차례로 클릭). 그러나 (a) 화면에 안내가 없다. (b) `useDrawSequence`의 `mapping` 초기값이 `null`이라 발표 화면을 다시 열면 저장된 지난 배치가 있어도 전부 "빈 자리"로 보이고 인쇄·이미지 저장도 잠긴다. 뽑기 직후가 아니면 바꿀 방법이 없다(v1은 가능). (c) **결함**: 교환마다 `recordAssignment`를 불러 직전 배치를 이력에 한 건씩 쌓는다. 이력은 최대 5건이라 세 번 바꾸면 진짜 이전 기록 세 건이 밀려나고, 다음 뽑기의 "이전 자리 피하기"가 실제로 앉은 적 없는 중간 배치를 기준으로 한다. 모둠 배치는 모둠 이력도 교환마다 쌓인다. (d) 첫 자리를 누르면 안내 문단이 새로 생겨 배치도 영역이 줄고 배율이 다시 계산돼 자리가 움직인다. |
| 4 | 금색 점은 `NoteSeat`의 `PushPin color="gold"`(고정 자리 표시)다. 뽑기 전 빈 화면에서도 보여 어느 자리가 고정인지 학생에게 드러나고, 인쇄물에도 찍히며, 이미지 저장은 고정 자리를 다른 색(`#FDE6B8`)으로 칠한다. |
| 덤 | (a) **U자 배치가 교사 미리보기·발표 화면 모두에서 한 곳에 겹쳐 그려진다.** 캔버스가 `w-full` + 백분율 좌표인데 부모가 폭을 정하지 않는 absolute 래퍼라 폭이 0으로 무너진다(발표 108px, 미리보기 174px). (b) 모둠 배치에서 역할 글씨가 이름표 **밖** 아래에 붙어 아래 줄 이름표에 가려지고, 역할이 있는 이름표만 위로 밀려 줄이 어긋난다. (c) 인쇄물에 토스트 알림이 찍힌다(fixed 요소). (d) 뽑는 동안 조작 막대를 언마운트해 배치도가 커졌다 작아진다. |

## 2. 결정

| 항목 | 결정 |
|---|---|
| 1 | 반영. 배치도가 가로로 꽉 차도록 이름표를 가로형으로 통일하고 화면 틀을 줄인다. "전체 화면" 버튼 추가. 수동 확대(+/-)는 만들지 않는다(자동 맞춤이 이미 최대). |
| 2 | 반영. 화면은 1번으로 가로형 배치도가 된다. 인쇄는 배치도 모양에 맞춰 용지 방향 자동 선택 + 용지에 꽉 차게. 배치도 90도 회전은 하지 않는다(칠판이 옆으로 가서 실제 교실과 안 맞음). |
| 3 | 설명 + 개선. 발표 화면은 지난 배치를 보여 준 채로 연다(사용자 선택). 안내 상시 표시, 이력 결함 수정, 교환 후 규칙 위반 재계산. |
| 4 | 반영. 학생이 보는 곳(발표 화면·인쇄·이미지)에서만 고정 표시를 뺀다(사용자 선택). 교사 화면 미리보기는 유지. |
| 덤 | 반영. 같은 파일을 고치며 모두 실제 오표시 결함이다. |

접근은 A안(가로형 이름표 통일 + 기존 자동 맞춤 유지). B안(화면 비율마다 이름표 비율 계산)은 복잡도 대비 이득이 적고, C안(90도 회전)은 방향 감각을 해쳐 기각.

## 3. 설계

### 3-1. 이름표·배치도 (`NoteSeat`, `SeatBoard`)

`lg`(발표·인쇄용)만 바꾼다. `sm`(교사 미리보기)은 U자 수정 외에는 그대로.

- `lg` 이름표는 모든 배치에서 가로형 **200 x 100px**. 시험대형·짝꿍도 슬롯 폭을 200px로 고정해 열 폭이 이름 길이에 따라 달라지지 않게 한다.
- `lg` 안 배치: 자리 번호는 왼쪽 위 모서리(절대 위치, 14px 안팎). 이름은 가운데, 기준 48px. 이름이 길면 글자 수에 따라 줄인다(4글자까지 48px, 그 이상은 폭 안에 들어가게 단계 축소, 한 줄 유지). "빈 자리" 문구는 작게(이름보다 확실히 작게).
- 모둠 역할은 이름표 **안** 아랫줄에 작게 넣는다(`NoteSeat`에 `role` prop). 카드 밖 역할 글씨와 그 여유(`ROLE_PAD`)는 없앤다. 이것으로 역할 가림·줄 어긋남(1절 덤 b)이 사라진다.
- 이름 글자를 담은 요소에 이름 전용 표식(예: `data-seat-name`)을 단다. 이미지 저장이 지금처럼 `span:last-child`로 이름을 읽으면 역할이 카드 안에 들어온 뒤 역할을 이름으로 읽게 된다.
- 자유배치·모둠(px 좌표 배치)은 `SLOT_PX.lg`가 200x100으로 바뀌면서 원본 책상 크기(custom 60x40, group 64x48) 대비 가로 배율이 세로 배율보다 커진다. 책상 한 개 = 이름표 한 칸이라 겹치지 않는 원칙은 그대로이고, 편집기보다 가로로 조금 넓게 그려지는 것은 받아들인다.
- **U자**: 반원 백분율 배치를 버리고, 코어가 주는 `row`/`col`(윗줄 row 0 = 칠판 쪽, 왼쪽 줄 col 0, 오른쪽 줄 col columns-1)을 CSS grid 칸에 그대로 놓는다. 비어 있는 안쪽 칸은 빈 공간. 선생님 시선은 시험대형처럼 행·열을 모두 뒤집는다. `sm`·`lg` 모두 적용(교사 미리보기 겹침도 해결).
- `SeatBoard`에 `showFixed?: boolean`(기본 `true`) 추가. `false`면 고정 자리도 일반 자리와 똑같이 그린다: 압정 없음, `data-state`는 `assigned`/`empty`, aria-label에 "(고정)" 없음. 뽑기 전 빈 화면도 마찬가지.

### 3-2. 발표 화면 틀 (`PresentPage`)

- 제목 칠판("6-5 자리 배치")을 없앤다. 반 이름은 조작 막대 왼쪽에 작게 표시한다(여러 반을 맡는 교사가 반을 확인하는 용도).
- 조작 막대는 얇게: 버튼은 모두 `md`, 막대 안쪽 여백 축소, 가능한 한 한 줄. 페이지 바깥 여백도 줄인다(모든 폭에서 약 12~16px).
- 뽑는 동안(카운트다운·셔플·줄 공개) 막대를 언마운트하지 않고 `invisible`로 가려 높이를 유지한다(배치도 크기 흔들림 제거).
- 막대 안에 **고정 높이 상태 칸**을 둔다. 표시 우선순위: 한 명씩 뽑기로 지금 공개하는 학생 이름(크게) > 교환 중 안내("3번 자리를 골랐습니다. 바꿀 자리를 누르세요 (같은 자리를 다시 누르면 취소)") > 교환 가능할 때 기본 안내("두 자리를 차례로 누르면 서로 바뀝니다") > 빈 칸. 지금의 별도 안내 문단(`swap-hint`)과 이름 문단(`lottery-name`)은 없앤다. 상태 칸 내용이 바뀌어도 막대 높이는 변하지 않는다.
- "전체 화면" 버튼: Fullscreen API(`document.documentElement.requestFullscreen`), `fullscreenchange`로 라벨을 "전체 화면"/"전체 화면 끝내기"로 바꾼다. `document.fullscreenEnabled`가 아니면 버튼을 숨긴다.
- 배율 계산(`ResizeObserver` + `offsetWidth/offsetHeight`, 0.4~2.6배 클램프)은 그대로.
- 실패 문구·규칙 위반 목록은 지금처럼 막대 위 블록으로 둔다(드물게 나타나므로 배치도가 한 번 줄어드는 것은 허용).
- `PresentPage.tsx`가 585줄이라 이번에 크게 손대는 두 덩어리를 파일로 뗀다: 이미지 저장 그리기(`renderBoardToCanvas` 계열)와 조작 막대. 동작 변경 없는 이동 + 아래 3-3·3-5의 수정.

예상 이름 크기(계산값, 구현 후 스크린샷으로 확인): 1920x1080 전체 화면 42px → 약 71px, 1920x937 창 28px → 약 61~71px, 1366x625 창 15px → 약 39~47px.

### 3-3. 인쇄

- 인쇄 시작 시점(인쇄 버튼과 Ctrl+P 모두 거치는 `beforeprint`, 그리고 버튼 경로)에서 화면 배치도의 변환 전 크기(`offsetWidth/offsetHeight`, 인쇄용 배치도와 같은 `lg` 크기)를 재서 순수 함수 `fitPrintPage(boardW, boardH)`로 방향과 배율을 정한다.
  - A4 가로·세로 각각의 인쇄 영역(여백 10mm, 96dpi 기준 px 환산, 제목 줄 높이 제외)에 들어가는 최대 배율을 구해 더 큰 쪽의 방향을 고른다. 배율은 위쪽을 2배로 묶는다.
  - 결과로 `@page { size: landscape|portrait; margin: 10mm; }`를 인쇄 전용 영역에 `<style>`로 넣고, 인쇄용 배치도에 CSS `zoom`을 준다(`zoom`은 레이아웃에 반영돼 페이지 나눔과 어긋나지 않는다).
  - 용지 크기는 강제하지 않는다(`size`에 방향만). 프린터 설정을 따르고, Letter처럼 조금 작으면 브라우저 축소 인쇄가 맞춘다.
  - 대가: 크롬 인쇄 창에서 가로/세로 선택지가 사라진다(자동 선택으로 대체).
- 한 장에 한 시점(학생 시선 / 선생님 시선) 구성은 유지. 제목은 `[ 6-5 · 학생 시선 ]`처럼 반 이름을 넣는다.
- 인쇄에서 토스트를 숨긴다(`present.css`의 print 블록에서 `[data-cork='toast']`). 기존 `@page { margin: 12mm }`는 새 규칙과 겹치지 않게 정리.
- 인쇄용 배치도도 `showFixed={false}`.

### 3-4. 자리 바꾸기

- 발표 화면을 열 때 `loadableLastAssignment(data)`로 지난 배치를 검사한다.
  - 불러오는 조건(모두 충족): `lastAssignment.mapping`이 비어 있지 않다 / 모든 좌석 번호가 현재 배치의 좌석이고 "빈 자리로 둔" 좌석이 아니다 / 배치된 이름 집합이 현재 명단과 정확히 같다(추가·삭제 없음, 중복 없음).
  - 충족하면 그 배치를 전부 공개된 상태로 시작한다: `mapping` = 지난 배치, `revealedSeats` = `'all'`, 버튼 라벨 "다시 뽑기", 교환·인쇄·이미지 저장 가능. 연출·효과음·컨페티 없음. 규칙 위반은 현재 규칙으로 계산해 보여 준다.
  - `lastAssignment`는 있는데 조건을 못 채우면 지금처럼 빈 화면으로 열고 토스트 "명단이나 배치가 바뀌어 지난 배치는 불러오지 않았습니다."를 띄운다. `lastAssignment`가 없으면 조용히 빈 화면.
- 교환 조작은 그대로(두 자리를 차례로 클릭, 빈 자리를 누르면 이동, 같은 자리를 다시 누르면 취소). 안내는 3-2 상태 칸.
- 교환 저장은 새 스토어 동작 `replaceLastAssignment(mapping)`:
  - `lastAssignment.mapping`만 바꾸고 `timestamp`는 그대로 둔다. `assignmentHistory`는 건드리지 않는다.
  - 모둠 배치이고 `groupHistory`의 마지막 항목 `timestamp`가 `lastAssignment.timestamp`와 같으면(= 이번 뽑기가 쌓은 항목) 그 항목의 `groups`만 바뀐 배치로 다시 계산해 교체한다. 다르면 모둠 이력은 건드리지 않는다.
  - `lastAssignment`가 없으면 아무것도 하지 않는다. Undo 대상이 아니다(`recordAssignment`와 같이 untracked).
- `useDrawSequence`: 옵션 `initialMapping`(위 검사를 통과한 지난 배치), `onSwapped(mapping)` 추가. `swap`은 더 이상 `onAssigned`를 부르지 않고 `onSwapped`를 부르며, 교환 뒤 `verifyAssignment`로 규칙 위반을 다시 계산한다. "다시 뽑기"는 지금처럼 `recordAssignment`로 저장(교환이 반영된 직전 배치가 이력으로 간다).
- 한계(이번에 안 함): 모둠 역할은 뽑은 그 화면에서만 보이고 다시 열면 표시되지 않는다. 교사 화면 미리보기에서의 교환은 넣지 않는다.

### 3-5. 고정 표시와 이미지 저장

- 발표 화면의 배치도와 인쇄용 배치도는 `showFixed={false}`. 교사 화면은 기본값(표시 유지).
- 이미지 저장: 고정 자리 전용 색을 없앤다(`data-state`가 `assigned`로 오므로 자연히 같은 색). 이름은 3-1의 이름 전용 표식으로 읽는다. 글자 크기는 상수(이름 13px, 번호 10px)가 아니라 이름표 상자 크기에 비례해 정한다(200x100 이름표에서 이름이 상자에 맞게 커 보이도록). 번호는 왼쪽 위.

## 4. 비목표

수동 확대 버튼, 배치도 90도 회전, `sm` 이름표 크기 변경(U자 제외), 교사 화면 미리보기 교환, 다시 연 배치의 모둠 역할 표시, 이미지 저장의 역할·모둠 이름 그리기.

## 5. 검증

- 단위(vitest): U자 격자 배치·좌석 상자 겹침 없음·선생님 시선 반전 / `lg` 슬롯 폭 통일 / 역할이 이름표 안 / `showFixed=false`면 압정·"(고정)" 없음 / 이름 길이별 글자 크기 / `loadableLastAssignment` 조건별 / `replaceLastAssignment`가 이력 수를 바꾸지 않고 짝이 맞는 모둠 이력만 교체 / `useDrawSequence`의 `initialMapping`·`onSwapped`·교환 후 위반 재계산 / `fitPrintPage` 방향·배율 / 발표 화면이 지난 배치로 열리면 인쇄·이미지 버튼 활성, 상태 칸 문구, 전체 화면 버튼.
- E2E(Playwright): 지난 배치가 보인다 → 두 자리 교환 → 새로고침 후 유지, `assignmentHistory` 길이 그대로 / 1920x1080·1366x625에서 이름 글자 크기 하한과 배치도 가로 사용률 / U자 좌석 상자끼리 겹치지 않음(교사 화면·발표 화면) / 인쇄 PDF가 가로 페이지 2장. 기존 "뽑기 전에는 이름이 보이지 않는다" 단정은 새 동작에 맞게 고친다.
- 눈 확인: 배치 5종 x 화면 3종(1920x1080, 1920x937, 1366x625) 스크린샷과 인쇄 PDF를 직접 본다. 테스트 통과만으로 완료 판정하지 않는다.
- 게이트: `npm run gate`(typecheck·lint·test·scan) + E2E 통과 → master 병합·푸시 → 라이브 확인.

## 6. 위험과 미검증

- 실제 인쇄 대화상자, Safari·Firefox 인쇄(`beforeprint` 지원 차이)는 PDF로만 확인한다.
- 자유배치·모둠은 편집기보다 가로로 넓게 그려진다(의도).
- 지난 배치 검사는 전부 아니면 전무다. 명단을 한 명만 바꿔도 지난 배치는 열리지 않는다(자리 번호가 어긋난 배치를 보여 주지 않는 쪽을 택함).
